# C 语言练习项目（Visual Studio）

中国大学 C 语言程序设计课程的 Visual Studio 练习项目合集（Project1 ~ Project37）。

## 结构

- `ProjectN/ProjectN.slnx` — Visual Studio 解决方案
- `ProjectN/ProjectN/源.cpp` — 源代码

## 使用

用 Visual Studio 打开任意 `ProjectN.slnx` 即可编译运行。

## 内容索引

| 项目 | 内容 |
|---|---|
| Project1 ~ Project16 | C 语言基础练习（见 `C语言代码仓库` 说明） |
| Project17 ~ Project37 | 选择结构、循环、函数等练习 |
